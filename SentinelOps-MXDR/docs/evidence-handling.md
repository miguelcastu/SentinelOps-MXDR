# Screenshot privacy and validation

This repository may be publicly visible. Screenshot sources are **not committed unredacted**. Mask Azure signed-in identities, email addresses, tenant IDs, subscription GUIDs, caller identities, secret values and other sensitive telemetry with **opaque rectangles**, never blur. Generic lab resource names and fictional customer names are intentionally retained.

The screenshots supplied for v0.1 were reduced to a compact palette and visible identifying sections were masked. Always visually inspect new evidence before commits. A GitHub repository marked public can be indexed, copied and forked; deleting a sensitive file later does not guarantee its erasure from history.

Do not claim that a screenshot shows a production customer, legitimate SOC alerts or IaC if it actually demonstrates a lab configuration or manual action.
